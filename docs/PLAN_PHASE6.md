# Phase 6 계획: "환경 우선" 모드와 비교 실험

작성 2026-11-05. 배경: 호성님은 정책·돈의 가치·이벤트·기술·내러티브 같은 외적 요소가 그래프를 결정한다고 본다.
지금 엔진은 "그래프 모양 우선"(가격 50%)이다. 두 방식을 같은 과거 시점들에서 나란히 돌려 어느 쪽이 이후 12개월 결과를 더 잘 설명하는지 데이터로 확인한다.

## 1. 질문을 먼저 고정한다 (사전 등록)

실험 전에 "무엇이 이기면 이긴 것인가"를 정해 두고, 실험 후에 바꾸지 않는다.

- **비교 대상 3개**
  - **기준선(Baseline)**: 매칭 없이 전체 과거의 12개월 수익 분포를 그대로 쓴다. 매칭이 이걸 못 이기면 매칭 자체가 무의미하다.
  - **모양 우선(Shape-first)**: 지금 엔진 그대로(가격 형태 50 / 매크로 30 / 업황 20).
  - **환경 우선(Regime-first)**: 아래 3절. 매칭 키가 환경·위치이고 모양은 보조.
- **평가 시점**: 1999-01부터 2025-10까지 매월 말 거래일, 약 320개. 각 시점은 그날까지의 데이터만 쓴다(룩어헤드 금지는 백테스트에도 적용).
- **각 시점에서 내는 것**: 상위 5개 국면의 12개월 뒤 수익률 분포(중앙값, 10%, 90%).
- **채점(모두 12개월 기준)**
  1. **구간 점수(interval score)**: 10~90% 구간의 폭 + 실제값이 구간 밖이면 벌점. 낮을수록 좋다. 주 지표.
  2. **적중률**: 실제값이 10~90% 안에 든 비율. 80%에 가까울수록 좋다(너무 높으면 구간이 쓸데없이 넓은 것).
  3. **방향 일치**: 중앙값의 부호와 실제 부호가 같은 비율.
- **승리 조건**: 전체 기간 구간 점수가 기준선보다 낮고, 시대별(1999–2006, 2007–2012, 2013–2019, 2020–2025) 4개 중 3개 이상에서도 낮다. 두 모드 중 이 조건을 만족하는 쪽이 이긴다. 둘 다 기준선을 못 이기면 "매칭이 분포를 좁히지 못한다"가 결론이고 그대로 보고한다.
- **과적합 방지**: 가중치·특징은 이 문서에 적은 대로 고정하고 백테스트 결과를 보고 조정하지 않는다. 조정하고 싶으면 2013년 이전 구간에서만 조정하고 2013년 이후로 재검증한다.

## 2. 왜 이렇게 채점하나 (쉬운 설명)

"맞혔다/틀렸다"로 채점하면 안 된다. 이 도구는 하나의 값이 아니라 분포를 내기 때문이다. 좋은 분포란 **실제값을 대체로 품으면서도 좁은** 분포다. 구간 점수는 그 두 가지를 하나의 숫자로 합친 것이다. 기준선과 비교하는 이유는, "닮은 과거 5개"가 "모든 과거"보다 나은지가 이 도구의 존재 이유이기 때문이다.

## 3. 환경 우선 모드의 매칭 키

측정 가능한 것만 넣는다. 전부 무료 소스.

| 그룹 | 특징 | 출처 | 비고 |
|---|---|---|---|
| 위치 (사이클 어디인가) | 고점 대비 낙폭, 고점 이후 거래일 수, 직전 1년·2년 수익률, 60일 실현 변동성 | 시세 | 모양 대신 "위치" |
| 돈의 가치 | 기준금리 수준·6개월 변화, 실질금리(기준금리 − CPI YoY), 10년물, 장단기 스프레드, 달러지수, M2 YoY, 연준 자산 YoY(2002~) | FRED (`M2SL`, `WALCL` 추가 수집) | 금리는 z-score뿐 아니라 **수준 차이**도 넣는다 |
| 정책·이벤트 | 최근 6개월 금리 방향(인상/동결/인하), 최근 6개월 내 정책·전쟁·충격 이벤트 유무 | FRED, events | 태그는 0/1 |
| 기술·업황 | WSTS 매출 YoY, YoY 6개월 변화 | WSTS | 지금은 극단값(+144%)이라 표준화 상한을 둔다(±3σ 클리핑) |
| 내러티브 (대리) | VIX 수준, SOX의 200일선 대비 괴리 | 시세, FRED | 선행 PER·자금유입은 무료 장기 데이터가 없어 이번엔 제외 |
| 모양 (보조) | 기존 DTW 모양 점수 | 엔진 | 가중치 10% |

거리: 그룹별 표준화 유클리드(각 시점까지의 expanding 통계), 그룹 가중치 위치 30 / 돈의 가치 25 / 정책·이벤트 10 / 업황 15 / 내러티브 10 / 모양 10. 상위 5개, 창 간 최소 간격 250거래일은 동일.

## 4. 산출물

- `stocker/ingest/fred.py`: `M2SL`, `WALCL` 기본 시리즈에 추가(수집기만 손봄).
- `stocker/similarity/regime.py`: 환경 우선 특징·거리·`score_regime()`. 기존 `score()`와 같은 `SimilarityResult`를 돌려준다(화면·API가 그대로 쓰도록).
- `stocker/similarity/config.py`: `mode: "shape" | "regime"` 추가. CLI `--mode regime`.
- `stocker/backtest/`: `harness.py`(시점 생성, 모드별 실행, 결과 저장 `backtest_runs` 테이블), `metrics.py`(구간 점수·적중률·방향 일치), `__main__.py`(`python -m stocker.backtest run --modes baseline,shape,regime`, `report`).
- `docs/BACKTEST_RESULTS.md`: 표 + 시대별 표 + 한 단락 결론. 숫자는 엔진이 생성, 결론은 1절 승리 조건으로 기계적으로 판정.
- React `/` 페이지 헤더에 모드 토글(모양 우선 / 환경 우선)과 "비교 결과 보기" 링크. 이건 Phase 5 완료 후.

## 6. 완료 기준

- `python -m stocker.backtest run` 이 세 방식의 320개 시점 결과를 10분 이내에 만든다.
- 룩어헤드 테스트: 임의 시점에서 그 이후 데이터를 잘라도 그 시점의 상위 5개와 분포가 같다.
- `docs/BACKTEST_RESULTS.md`에 1절 승리 조건에 따른 판정이 적혀 있다. 어느 쪽이 이기든, 혹은 둘 다 기준선을 못 이기든 그대로 적는다.

## 7. 미리 말해 두는 한계

- 320개 시점은 서로 겹친다(이웃한 달은 거의 같은 데이터). 실질적인 독립 표본은 사이클 수인 6~8개에 가깝다. 시대별 결과가 갈리면 "결론 없음"이 정직한 답이다.
- 내러티브는 대리 지표(VIX, 200일선 괴리)뿐이다. 호성님이 말한 "사람들의 서사"를 제대로 재려면 밸류에이션·자금흐름 데이터가 필요하고, 이는 유료거나 2010년 이후만 있다.
- 환경 우선이 이겨도 "외적 요소가 그래프를 결정한다"의 증명은 아니다. "환경이 닮은 시점들의 결과가 더 비슷하게 모였다"까지다.
