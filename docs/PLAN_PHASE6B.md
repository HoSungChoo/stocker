# Phase 6B 사전 등록: 닮은 과거를 넉넉히 뽑으면 기준선을 이기는가

작성 2026-11-06. Phase 6 결과(`docs/BACKTEST_RESULTS.md`): top_k=5로는 모양 우선·환경 우선 모두 기준선을 못 이겼다(구간 점수 3.33/3.12 vs 1.65, 적중률 33~37% vs 88%).
구조적 요인: 표본 5개로 만든 10~90% 구간은 사실상 5개의 최소~최대라 너무 좁다. 이 실험은 **설정을 조정해 이기려는 것이 아니라 질문을 바꾸는 것**이다. 결과를 보고 다시 바꾸지 않는다.

## 1. 질문
"닮은 과거를 10·20·30개로 뽑아 분포를 만들면, 매칭 없는 전체 과거 분포(기준선)보다 12개월 결과를 더 잘 설명하는가?"

## 2. 비교 대상 (모두 적합 기준 23절 적용, ok 이상만으로 분포)
| 이름 | 모드 | top_k | min_gap(거래일) |
|---|---|---|---|
| baseline | 매칭 없음 | — | — |
| shape_k5 (참고, Phase 6과 동일) | 모양 우선 | 5 | 250 |
| regime_k5 (참고, Phase 6과 동일) | 환경 우선 | 5 | 250 |
| shape_k10 | 모양 우선 | 10 | 250 |
| regime_k10 | 환경 우선 | 10 | 250 |
| shape_k20 | 모양 우선 | 20 | 126 |
| regime_k20 | 환경 우선 | 20 | 126 |
| shape_k30 | 모양 우선 | 30 | 63 |
| regime_k30 | 환경 우선 | 30 | 63 |

min_gap을 줄이는 이유: 32년 역사에서 서로 1년 이상 떨어진 창은 최대 32개라 k=20·30에 gap 250은 불가능하다. gap이 작아지면 이웃한 날짜(거의 같은 국면)가 여러 개 뽑혀 실질 독립 표본이 k보다 작다는 점을 결과 해석에 명시한다.
`applicable` 조건은 그대로 "ok 이상 2개 이상"이다.

## 3. 채점과 승리 조건 (Phase 6과 동일)
- 시점: 1999-01 ~ 2025-10 매월 말 거래일(322개), 각 시점은 그날까지의 데이터만.
- 주 지표 구간 점수(α=0.2), 보조 적중률·방향 일치. 12개월(252거래일).
- 승리: 전체 구간 점수 < 기준선 **그리고** 시대 4개 중 3개 이상 < 기준선.
- 추가 보고: 적중률이 60~95% 범위에 들어오는지(구간 폭이 현실적인지), 평균 실질 표본 수(선택된 창 중 서로 126거래일 이상 떨어진 개수).

## 4. 해석 규칙 (미리 적어 둔다)
- k가 커질수록 기준선에 가까워지는 것은 당연하다(k=7813이면 기준선과 같다). 따라서 **k=10·20에서 기준선을 이기는지**가 핵심이고, k=30에서만 이기면 "매칭 효과는 미약"으로 적는다.
- 어느 k에서도 못 이기면: "매칭은 12개월 분포를 좁히지 못한다"를 확정하고, 서비스의 상위 국면은 통계가 아니라 사례로 다룬다(화면 문구 유지).
- 환경 우선만 이기면 "환경 매칭은 효과가 있다, 모양 매칭은 없다"로 적는다.

## 5. 산출물
- `stocker/backtest`에 모드별 (top_k, min_gap) 설정 추가. `python -m stocker.backtest run --preset phase6b`.
- `docs/BACKTEST_RESULTS_K.md` 자동 생성(판정·전체·시대별 표·실질 표본 수).
- Phase 6 결과 문서는 수정하지 않는다.

## 6. 한계 (미리)
- 322개 시점은 겹친다. 실질 독립 사이클은 6~8개.
- k=20·30은 이웃 날짜 중복으로 "닮은 과거 n개"의 의미가 약해진다. 실질 표본 수를 같이 본다.
