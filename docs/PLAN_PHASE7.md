# Phase 7 계획: 내러티브 레이어 (유튜브 여론 + 과거가 있는 심리 지표)

작성 2026-11-06. 호성님 제안: "유튜브에서 미국 반도체 주식을 다루는 사람들의 최근 한 달 의견을 모아 가중치를 적용해 데이터를 만들자."
결론: 실현 가능. 단 두 갈래로 나눈다. **(A) 과거가 있는 심리 지표**는 매칭·백테스트에 넣고, **(B) 유튜브 여론**은 "현재 분위기 게이지"로 표시하며 기록을 쌓아 1~2년 뒤 역지표로 검증한다.

## 0. 원칙
- 유튜브 여론은 2018년 이후에만 존재하므로 1994~2017 국면과 비교할 수 없다. 매칭 잣대에 넣지 않는다.
- 여론은 주가를 따라가는 경향이 있다. "오른다"의 신호가 아니라 "과열인가"의 역지표 후보로 다룬다. 검증 전에는 표시만 한다.
- 원문(자막·댓글)은 저장하지 않는다. 판정 결과(입장·확신·태그)만 저장한다. 약관·저작권·개인정보 부담을 줄이기 위해서다.
- 한국어 채널과 영어 채널은 다른 지표다. 분리해 집계한다.

## A. 과거가 있는 심리 지표 (백테스트·환경 우선 모드용)

| 지표 | 범위 | 출처 | 특징으로 쓰는 값 |
|---|---|---|---|
| AAII 개인투자자 심리조사 | 1987~ 주간 | AAII 공개 엑셀(무료) | 강세−약세 스프레드, 4주 평균, 그 시점까지의 백분위 |

| 구글 트렌드 | 2004~ 주간 | pytrends 또는 수동 CSV | "semiconductor stocks", "NVDA stock", "SOXL"(2010~), 한국어 "반도체 주식", "SOXL" — 13주 변화, 백분위 |

- 환경 우선 모드의 "내러티브" 그룹(현재 VIX·200일선 괴리뿐)에 추가. 가중치 10%는 유지. **Phase 6 백테스트가 끝난 뒤** 추가하고, "내러티브 그룹 포함/제외" 두 줄을 백테스트에 더해 효과를 따로 본다.
- 평가표에 "그때 개인투자자 심리 / 지금" 행이 생긴다.

## B. 유튜브 현재 분위기 게이지

### B1. 수집 (`stocker/narrative/youtube.py`)
- 유튜브 Data API v3(무료, 하루 10,000유닛). 검색어 세트: 영어 `semiconductor stocks`, `SOXL`, `NVDA stock`, `Micron stock`, `SMH ETF`; 한국어 `반도체 주식`, `SOXL`, `엔비디아 주가`, `마이크론`. `publishedAfter` = 30일 전, 언어·지역 분리.
- 영상 메타(제목·설명·조회수·좋아요·길이·채널·게시일)와 상위 댓글 20개. 자막은 자동 생성 자막을 비공식 도구로 시도하고, 막히면 제목·설명·댓글로 대체(판정 신뢰도 낮음으로 표시).
- 채널 화이트리스트(선택): 호성님이 아는 채널을 `seed/narrative/channels.json`에 적으면 우선 수집.
- 테이블: `yt_channels(channel_id, name, lang, subscribers, first_seen)`, `yt_videos(video_id, channel_id, published_at, title, views, likes, duration_s, lang, has_transcript)`.

### B2. 판정 (`stocker/narrative/classify.py`)
- OpenAI `gpt-6.1-sol` 구조화 출력. 영상마다: `stance`(−2 강한 약세 … +2 강한 강세), `confidence`(0~1), `horizon`(단기/중기/장기), `thesis_tags`(AI 설비투자, 메모리 사이클, 금리, 관세·수출규제, 밸류에이션, 차트, 기타), `instruments`(SOXL, NVDA, …), `is_opinion`(뉴스 요약인지 의견인지).
- 비용: 영상당 입력 3~8천 토큰, 월 200편이면 약 2~5달러. `REPORT_LLM=on`일 때만 실행.
- 테이블 `yt_stances(video_id PK, stance, confidence, horizon, tags, instruments, is_opinion, model, classified_at)`.

### B3. 가중치와 집계 (`stocker/narrative/aggregate.py`)
- 영상 가중치 = 채널 신뢰도 × 최신성 감쇠(반감기 10일) × log(조회수+1). 채널 신뢰도는 처음엔 전부 1. B4가 쌓이면 적중률로 바뀐다.
- 일간 집계 `narrative_daily(date, lang, n_videos, bull_share, weighted_stance, attention, dispersion, top_tags)`. `attention` = 최근 7일 조회수 합의 90일 평균 대비 비율. `dispersion` = 입장의 표준편차(의견이 갈리는 정도).
- 게이지 라벨: weighted_stance 백분위(기록 쌓이면)로 과열/강세/중립/약세/공포. 기록이 6개월 미만이면 라벨 대신 숫자만.

### B4. 채널 적중률 (`stocker/narrative/track_record.py`)
- 매월 말 채널별 평균 입장을 저장하고, 63거래일 뒤 SOX 수익률과 대조. 적중 = 입장 부호와 수익 부호 일치. 채널별 적중률·표본 수·보정(과신 정도) 저장 `channel_track_record`.
- 신뢰도 = 적중률을 표본 수로 보정(표본 10개 미만이면 0.5 쪽으로 수축). 2027년 중반부터 의미 있는 숫자가 나온다.

### B5. 화면과 보고서
- `/` 헤더 옆 "지금 분위기" 카드: 강세 비율, 가중 입장, 관심도, 의견 분산, 한국어/영어 두 줄, 최근 30일 스파크라인, 상위 영상 5개(제목·채널·입장). 고정 문구: "이 게이지는 유사도 계산에 쓰이지 않는다."
- 아침 보고서·텔레그램에 한 줄 추가.
- 채널 리더보드 페이지는 B4 데이터가 쌓인 뒤.

### B6. 검증 (사전 등록)
- 12개월 뒤: `bull_share` 상위 10% 날들의 이후 63일 수익이 하위 10% 날들보다 낮은지(역지표 가설). 12개월은 사이클 한 개도 안 되므로 "참고"까지만 결론 낸다.

## C. 추가 아이디어 (우선순위 낮음, 기록용)
1. **서사 태그 타임라인**: 매월 지배적인 논거(AI 설비투자 → 메모리 사이클 → 관세 …)의 점유율 변화를 띠 그래프로. 서사가 바뀌는 시점이 국면 전환과 겹치는지 본다.
2. **의견 vs 가격 선후 관계**: 가중 입장과 SOX 수익률의 교차상관(±60일). 여론이 가격을 따라가는지 앞서는지를 수치로.
3. **내 생각 기록**: 호성님이 매월 자신의 입장(−2~+2)과 근거 한 줄을 기록 → 매매 복기와 같이 사후 대조. 유튜버와 같은 잣대로 자기 적중률을 본다. 이 서비스의 원래 목적(판단 교정)에 가장 직접적이다.
4. **한국 vs 미국 괴리 지표**: 두 언어권 가중 입장의 차이. 서학개미 쏠림 신호.
5. **실적 콜 어조**: NVDA·MU·TSM 실적 콜 발언의 어조를 같은 분류기로. 공개 스크립트의 저작권 확인 필요.
6. **뉴스 테마(GDELT, 2015~)**: 반도체 관련 기사량과 톤. 유튜브보다 과거가 길어 중간 다리 역할.
